# ForgedMoba Engineering Audit — 2026-09-22

Baseline: `main@9afa67738ab9e5217fac73d19917086d63f32923`.

## Verified baseline

- 23 unique hero IDs in `src/game/heroes.ts`.
- 39 unique item IDs in `src/game/items.ts`.
- `src/game/engine.ts` is ~5k lines and combines simulation, AI, browser input, Canvas rendering and effects.
- `src/App.tsx` is ~1.5k lines and owns broad UI/screen responsibilities.
- Legacy simulation uses variable `requestAnimationFrame` delta and `Math.random()`.
- Server matchmaking creates match IDs but the baseline does not join sockets to match rooms.
- The baseline websocket token is sent by the client but not verified by the server.
- Baseline auth is in-memory and development-only.
- Admin content is localStorage-based and therefore cannot be authoritative for online matches.
- Baseline had no repository CI workflow or automated test script.

## Foundation decision

Do not rewrite the game. Preserve the playable legacy engine while extracting a deterministic, serializable simulation core behind strict boundaries.

Rollback netcode is not the first networking milestone. The primary target is:
server authority + fixed tick + client prediction + reconciliation + interpolation.
